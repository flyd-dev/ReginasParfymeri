# Funn i dagens kundereise – og svaret i den nye nettbutikken

Gjennomgått på nettbutikk.reginaparfymeri.no og reginaparfymeri.no 26.10.2026.

| Funn i dag                                                                                                                     | I den nye nettbutikken                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Hovedmenyen har 10 punkter og over 100 underkategorier i versaler, flere med 1–2 produkter (33 stk.), og «Tilbehør → Tilbehør» | Sju hovedkategorier med megameny (tastatur), tomme kategorier skjult, normal skrift                 |
| Toppstripen sier at «nettbutikken fylles opp» med emojier – signaliserer at butikken ikke er ferdig                            | Toppstripe med tre bekreftede fordeler fra vilkårene                                                |
| Påskekampanje står på forsiden i oktober                                                                                       | Kampanjebanner fra WordPress med start- og sluttdato; forsvinner av seg selv                        |
| Engelske knapper («Quick view», «Add to wishlist», «Login / Register», «Lost your password?»)                                  | All tekst på norsk                                                                                  |
| «Nyhet» og «Utvalgt» på nær alle produkter, «Bestselgere» uten grunnlag                                                        | Merker bare med grunnlag: Utsolgt, Få igjen, Tilbud, Nyhet (publisert siste 45 dager i WooCommerce) |
| Variable produkter viser bare «Velg alternativ» og et prisspenn                                                                | «fra kr …» på kortet; på produktsiden pris og lager per valgt størrelse/farge                       |
| Lagerstatus vises først etter valg av variant                                                                                  | Utsolgte valg er streket over før valg; status for valgt variant etterpå                            |

| Søket finner bare i navn                                                                                                       | Hurtigsøk i merke, navn, kategori og beskrivelse, med produkter, merker og kategorier               |
| Duftnoter står begravd i beskrivelsen                                                                                          | (ikke med i denne versjonen)                                                                        |
| Produktnavn i versaler med merket først («PARFUMS DE MARLY – LAYTON EDP SPRAY»)                                                | Merket for seg, navnet rolig: «Layton EdP Spray»                                                    |
| Hvite produktbilder på hvit side                                                                                               | Bildene står på papirflate (--paper) med multiply, så det hvite smelter inn                         |
